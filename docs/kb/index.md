# True — knowledge base index
Owner: knowledge-keeper · Last verified: 2026-09-30

## What it is
A lean, native macOS terminal (tabs + splits) with an **Agents mode**: build Claude agents as character cards, wake them into tabs, see who is working / needs you, and a **Hub** of every Claude session on the Mac. Replaced Axon as Yahia's cockpit on 2026-09-30. [source: SPEC.md:1-9; ~/.claude/projects/-Users-y/memory/project_true.md]

## Who it's for

Build `.app` with `scripts/package.sh` (never launches it). Gates: see [conventions.md](conventions.md). Agents must not launch, quit or kill True.app. [source: SPEC.md:29-38]
