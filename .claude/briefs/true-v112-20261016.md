## 1. Auto-update (public build only)
Goal: a friend on v1.1.2 gets every later release without downloading by hand; the existing "Restart to update" pill
(`Views/RestartPill.swift`, `Model/BuildFreshness.swift` — fires when the binary on disk changes) does the last step.
- Enabled ONLY when Info.plist has `TrueUpdateRepo` (e.g. `yahiaelmahdi7-bit/true-terminal`). Add that key in
  `scripts/public/scripts/package.sh` only — the private `scripts/package.sh` must NOT get it (Yahia's private build has
  Nova; a public update would erase it). No key → updater is fully inert (no network).
- Check: on launch (+30 s) and every 24 h, GET `https://api.github.com/repos/<repo>/releases/latest`. Compare `tag_name`
  (strip `v`) with CFBundleShortVersionString using numeric semver compare (pure, unit-tested). Skip drafts/prereleases.
- Download zip + .sha256 to a temp dir; verify SHA-256 (pure helper, tested); `ditto -x -k` to staging; verify the staged
  app's CFBundleIdentifier equals ours, its LSMinimumSystemVersion <= running OS, `codesign --verify --deep` passes, and
  version > ours. Any failure → abandon, log one line, retry next cycle. Never partial-replace.
- Install: if `Bundle.main.bundleURL` is writable and not App-Translocated (path contains `/AppTranslocation/` → not
  writable): move current bundle to a temp backup, move staged bundle into place (same volume → rename), delete backup on
  success, restore it on failure. Strip `com.apple.quarantine` from the staged copy if present. Then the existing
  BuildFreshness watcher shows "Restart to update".
- Not writable → don't install; show a small non-modal notice "True <v> is out" with a button opening the release page.
- Settings: a "Check for updates automatically" toggle (default ON) + "Check now" button wherever app settings live.
- Pure logic in its own file (`Model/UpdateLogic.swift`), side effects in `Model/Updater.swift`. Tests for: semver compare,
  checksum verify, translocation/writability decision, feed parsing (fixture JSON), inert without the plist key.
