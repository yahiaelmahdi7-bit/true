## Architecture (build toward this)
find (Clip Studio engine) -> OpenChatCut project per moment (source span + word transcript) -> OpenChatCut agent edits, taught by our prompt AND calling OUR tools -> export mp4 -> Clip Studio QC + campaign gates -> queue -> slot post/submit (unchanged).
- Our tools as an MCP server: ~/Projects/clip-studio/engine/clipengine/mcp_tools.py (OUR code, our license) exposing the tools2 registry + what the edit needs: face track / smooth_reframe crop path, who_talks, speaker layout (stack/card/crop), spoken-only word captions, bleep (campaign profanity), hook_finder/cold open, text_guard, grade/luma, caption_readability, qc_score, campaign rule checks. Each tool returns data/instructions OpenChatCut applies to its timeline (crop keyframes, cut list, caption words+times, mute spans...).
- OpenChatCut fork at ~/Projects/openchatcut (pin + record base sha; AGPL — all changes to it stay in that repo, never copy its code into clip-studio or ~/Projects/true; True's public export is MIT). Register our MCP server in it; add a headless/CLI entry if missing ("edit project with prompt -> export") so the engine can drive it without the GUI.
- Teaching prompt: ~/Projects/openchatcut/teach/clip_editor_prompt.md built from ~/Projects/clip-studio-research/clipfarm-course/NOTES.md (+ EDIT-SPEC.md if present; another builder writes them — poll every 5 min up to 3 h; start with steps 1-3 meanwhile) + settled rules: 1080x1920 HD masters ~12-16 Mbps, captions = only spoken words, on time, big + readable whole clip, face in first seconds, NO word punch-in zooms, NO pop/boop SFX (Yahia 2026-10-14), no music on Solved (campaign music rules), no mid-thought cuts, no ad reads, stack/card two-speaker layouts never zoom.
- Engine side: render path flag CLIP_EDITOR=openchatcut (default stays current renderer until Yahia OKs the proof). engine/clipengine/occ.py = driver (create project, run agent with prompt, export, return path + features JSON incl. which tools were called). render_moment routes through it when the flag is set; same features/QC contract so autopilot/slot/verify keep working.
- OpenChatCut's GUI timeline = the optional manual edit (Edit Room / PB Blake hands-on pass): an engine call that opens a clip's project in it.
